# TUV Thuringen SouthAsia — website

Next.js (App Router, TypeScript) + Tailwind CSS + Sanity (project `lfctwwh9`, dataset `production`) + Motion + three.js. Hosted on Vercel. Domain: tuv-tsa.com.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Exact dependency versions are pinned in `package.json`.
